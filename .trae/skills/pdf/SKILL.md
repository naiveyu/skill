# PDF Skill

This skill provides advanced PDF handling capabilities.

## Usage Guidelines
- Extract text and metadata from PDF files.
- Summarize long PDF documents.
- Merge or split PDF files.
- Convert other document formats (like docx) to PDF.

## Examples
- "Summarize the attached research paper PDF."
- "Extract all tables from this PDF report."
