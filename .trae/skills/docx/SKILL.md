# Word (docx) Skill

This skill allows the agent to handle document processing and creation.

## Usage Guidelines
- Generate structured documents with headings, paragraphs, and lists.
- Support for inserting images, tables, and page numbers.
- Useful for drafting project documentation, READMEs in docx format, or formal letters.

## Examples
- "Write a project proposal in a Word document."
- "Format this text into a professional report with a table of contents."
