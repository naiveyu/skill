# PowerPoint (pptx) Skill

This skill allows the agent to create and structure professional PowerPoint presentations.

## Usage Guidelines
- Use this skill to define slide layouts, titles, and content.
- Support for adding images, tables, and charts to slides.
- Can be used to export existing content into a presentation format.

## Examples
- "Create a 5-slide presentation about AI Agents."
- "Add a new slide to my deck summarizing the project timeline."
