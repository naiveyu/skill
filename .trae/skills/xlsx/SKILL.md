# Excel (xlsx) Skill

This skill enables the agent to perform advanced spreadsheet operations.

## Usage Guidelines
- Create new Excel workbooks and worksheets.
- Write formulas, format cells, and create pivot tables.
- Analyze data from CSV or other sources and present it in Excel format.

## Examples
- "Generate an Excel sheet with the monthly sales data."
- "Create a budget tracker with automated sum formulas."
