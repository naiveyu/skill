# INote

**本地优先的 AI 笔记应用** — 数据存你本地，AI 伴你思考，一键发布全网。

> Markdown + Git + AI + 多媒体 + 跨设备同步 + 社交发布，全在一个应用里。

---

## 为什么选 INote？

| 痛点 | 市面方案 | INote 的做法 |
|------|----------|-------------|
| 数据隐私风险 | Notion/语雀 存在云端，随时可能关停或泄露 | 全部数据以标准 `.md` 文件存本地，你永远拥有 |
| 版本管理缺失 | 大多数笔记应用只保留最新版本 | 内置 Git，每次保存都有记录，精确回滚任意版本 |
| AI 整合割裂 | 需要在笔记和 AI 工具之间反复切换 | AI 助手内嵌编辑器，支持 Claude/GPT/Kimi 等流式对话 |
| 格式私有锁定 | Notion 导出格式残缺，语雀迁移困难 | 标准 Markdown，任何编辑器都能打开，零锁定 |
| 发布繁琐 | 写完还要手动复制粘贴到各平台排版 | 一键发布微信公众号、小红书、Twitter |
| 多媒体割裂 | PDF/图片/视频需要切换到其他应用 | 内置 PDF 阅读标注、图片查看、视频播放剪辑 |
| 跨设备同步依赖云 | 需要订阅云服务才能手机电脑同步 | LAN 局域网直连 + BLE 蓝牙，不过云同步 |

## 核心功能

### 笔记编辑

- **三种编辑模式**：所见即所得（Milkdown WYSIWYG）、源码模式（CodeMirror）、块编辑模式（BlockNote，类 Notion 体验）
- **多标签页**：同时打开多个文件，标签页式管理
- **自动保存**：编辑后 1 秒自动写入文件系统
- **YAML Front Matter**：自动维护 `title / created / updated / tags` 元数据
- **目录大纲**：实时解析 H1-H6 标题，侧边栏点击跳转

### Git 版本管理

- 内置 isomorphic-git，无需系统安装 Git
- 每次保存自动提交，保留完整历史
- 支持查看文件历史、精确回滚到任意版本
- 版本提交前自动更新 `updated` 时间戳，确保历史记录准确

### 文件管理与搜索

- **文件树**：文件夹层级浏览，支持新建、重命名、删除（移入回收站）
- **标签系统**：从 Front Matter 自动同步标签，SQLite 存储，支持按标签筛选
- **全文搜索**：FlexSearch 引擎，毫秒级响应，支持中文

### AI 智能助手

两种模式，满足不同需求：

| 模式 | 适用场景 |
|------|---------|
| **Claude Code CLI** | 本地已安装 `claude` 命令，直接调用，免费额度内使用 |
| **API Key** | 自带 Key，支持 Anthropic Claude、OpenAI、Kimi、豆包等任意兼容接口 |

- 悬浮按钮快速唤出，不打断写作流
- 流式输出，实时看到 AI 回复
- 支持将 PDF 内容、标注、当前页作为 AI 上下文输入

### PDF 阅读与标注

直接在应用内打开 PDF，支持：

- **高亮**、**下划线**、**便签**、**文字注释**、**区域框选**、**手写墨迹** 六种标注
- 标注数据以 `.pdf.meta.json` Sidecar 文件存储，不修改原 PDF，随工作区同步
- 标注内容参与标签系统，可按标签检索 PDF 文档
- PDF 内容可作为 AI 对话上下文

### 图片查看

内置图片查看器，无需切换到系统应用：

- 支持 `.jpg / .jpeg / .png / .gif / .webp / .bmp / .ico / .avif / .tiff`
- 缩放（Ctrl+滚轮）、平移拖拽
- 适应窗口 / 100% / 200% 快速切换

### 视频播放与剪辑

内置视频播放器，并支持基础剪辑导出：

- 支持 `.mp4 / .mov / .avi / .mkv / .webm / .m4v / .wmv / .flv` 等
- 自定义时间轴：拖拽 In/Out 手柄标记片段
- 键盘快捷键：`Space` 播放/暂停，`[` 设置入点，`]` 设置出点，`←/→` 跳 5 秒
- 一键导出片段（调用系统 FFmpeg 无损剪辑，显示实时进度）

### 一键社交发布

从编辑器直接发布到：

| 平台 | 说明 |
|------|------|
| **微信公众号** | 自动填充图文编辑器，保存为草稿 |
| **小红书** | 生成图文笔记，自动填写标题正文 |
| **Twitter / X** | 超过 280 字自动拆分为 thread |

技术方案：Puppeteer + Chrome DevTools Protocol，使用本机 Chrome 持久化登录状态，无需重复登录。

### 跨设备同步（无需云）

桌面端与手机端直接同步：

- **局域网 Wi-Fi**：mDNS 自动发现设备，无需手动配置 IP
- **BLE 蓝牙**：Wi-Fi 不可用时自动降级
- **首次配对**：扫码或 PIN 码，后续自动授权
- **冲突处理**：时间戳比较，新版本优先；时间相同则标记冲突

### 移动端（Android）

配套 Android 应用（Expo SDK 52）：

- 文件树浏览、笔记查看编辑
- 全文搜索、标签筛选
- 与桌面端局域网同步
- 用户账号登录

### 账号与更新

- 用户账号系统（JWT 认证），跨设备身份同步
- 应用自动检测新版本并提示更新
- 内置用户反馈入口

## 差异化优势

**1. 真正的 Local-First**
不只是「可以离线」，而是数据从来不经过任何服务器。同步走局域网直连，发布走本机 Chrome，AI 走本地 CLI 或自己的 Key。

**2. Git 是一等公民**
不是插件，不是额外配置，开箱即用。每次保存即提交，精确追溯每个字的改动历史。

**3. 全媒体工作台**
文字、PDF、图片、视频都能在同一个窗口处理。视频还能标记片段后直接剪辑导出，这在笔记应用里极为罕见。

**4. 写完即发布**
从写作到发布微信/小红书/Twitter 的路径缩短到一次点击，对内容创作者价值极大。

**5. AI 不绑架你**
支持 Claude CLI（用自己的 Claude Code 额度）或任意 API Key，没有平台锁定，没有强制订阅。

## 快速开始

```bash
git clone https://github.com/this-spring/ai-note.git
cd ai-note
pnpm install
pnpm dev          # 启动桌面应用
pnpm dev:mobile   # 启动移动端
pnpm dev:website  # 启动官网
```

**环境要求**：Node.js ≥ 18、pnpm ≥ 8

**可选依赖**（不影响核心功能）：
- `ffmpeg`（视频剪辑）：`brew install ffmpeg`
- `claude` CLI（AI 本地模式）：参考 [Claude Code 文档](https://docs.anthropic.com/claude-code)
